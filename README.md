# fedrigoni_project
Il progetto punta a digitalizzare i turni Fedrigoni. Utilizzando algoritmi o tool specifici, automatizza la pianificazione rispettando vincoli di ferie (max 4-5 persone) e specializzazioni. Il sistema reagisce in tempo reale a imprevisti come le malattie, ricalcolando i turni per evitare il fermo dei macchinari.
